# ECEN 225 Lab Repository

## Introduction

Welcome to ECEN 225! This README file will help you to learn about the first set of labs. These labs are designed to teach you to how to use Linux systems, and will teach you some C programming principles you will need when creating your doorbell software.

You will also practice writing some basic documentation by filling out your own README file describing what you did in each lab. A template called `readme_practice.md` is included to help you with that.

## Using This Repository

Within this repository are the following labs:

- **Lab 02: Command Line**: Practice working with Linux systems, and using the command line.
- **Lab 03: C Programming Part-1:** Introduction to reading, writing, and compiling C code.
- **Lab 04: C Programming Part-2:** Introduction to data types, strings, and more C topics.
- **Lab 05: Image**: More advanced data manipulation practice.

Each of these labs has a page on the ECEN 225 website that details how they should be done.
